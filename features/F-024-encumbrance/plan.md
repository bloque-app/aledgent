# F-024 — Encumbrance under standing rules

| | |
|---|---|
| Milestone | Later (after V0) |
| Track | D |
| Status | Not planned in detail. This page records intent and blockers only |

## Goal
The third balance kind, encumbered, exists in the model from V0 (`REQ-KER-3`) but nothing places or lifts an encumbrance. This feature adds the operator operations to encumber and disencumber value under a standing rule, visible to the holder and never released automatically.

## Spec traces
`DEF-11`, `US-C5`, `REQ-KER-3`, `REQ-OS-2`

## Why it is later
The kernel's third layer has no lifecycle, so this follows the holding-position pattern of `DEC-2`. Starts when a story needs it.

## Before this is planned
Write a full `plan.md` and `tasks.md` in the same format as the V0 features, once its blocker is resolved.
