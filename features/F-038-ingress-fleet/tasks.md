# F-038 — tasks

`PLAN.md` `DEC-27` (proposed 2026-10-15, waits for the owner) and the `F-038` row of §4. The Agent's package
and runtime bytes do not change (`DEC-27` (i)): every task is in ingress, the core host's host side, or docs.
