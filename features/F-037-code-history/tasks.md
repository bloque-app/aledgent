# F-037 — tasks

Amendment 0023 (code history and upgrades), ruled by the owner on 2026-10-08 (`a0023-q1` to `a0023-q9`), and
amendment 0033 (the code history independent of the platform), ruled on 2026-10-17; `PLAN.md` `DEC-26`. The
cases `AC-K7.1` to `AC-K7.11` are registered as pending (`crates/conformance/src/cases/f037.rs`). After
`F-036`, before `F-021`. Design: `plan.md`.

The table is in build order. Task ids are stable, so they are not in sequence: `T-037-14` to `T-037-17` were
added by amendment 0033.
